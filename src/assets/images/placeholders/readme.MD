# Placeholder Asset Directory

This directory exists to hold clearly marked temporary visual assets during development.

## Naming requirement

Every temporary asset must begin with:

```text
PLACEHOLDER-
```

Example:

```text
PLACEHOLDER-hero-resin-bound.jpg
```

## Replacement requirement

Every asset must be recorded in:

```text
src/data/assetManifest.js
```

Do not use untracked temporary assets in production code.

## Important

Do not use stock imagery, copied project imagery, or inferred project details without explicit approval.
