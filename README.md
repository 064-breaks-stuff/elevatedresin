# Elevated Resin Creations

A custom React and Vite marketing website for Elevated Resin Creations.

## Stack

- React
- Vite
- JavaScript
- Vanilla CSS
- React Router
- Anime.js
- Lucide React
- React Helmet Async
- Yet Another React Lightbox

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Implementation Order

1. P0 — Project foundation
2. P1 — Homepage
3. P2 — Shared conversion system
4. P3 — Services hub

6. P5 — Projects/Gallery
7. P6 — Glow Rock page
8. P7 — Rock Crete page
9. P8 — Resin Wall page
10. P9 — FAQ page
11. P10 — Contact and Thank-you pages
12. P11 — About page
13. P12 — Legal pages and 404
14. P13 — Launch hardening
15. P14 — Post-launch improvements

Do not deviate from this order without explicit approval.

## Placeholder assets

All temporary assets must use the `PLACEHOLDER-` naming convention and be tracked in:

```text
src/data/assetManifest.js
```

Replace every placeholder with an approved Elevated Resin Creations asset before production launch.

## Form integration

The website uses the approved GoHighLevel embed form. Do not add a competing custom form or alternate enquiry backend without explicit approval.
